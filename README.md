# HotelBomPraCachorro
Esse site tem o proposito de servir como base para algo maior futuramente. O Hotel Bom pra Cachorro foi feito como um mini gerenciador de hotel para cachorro, com intuito de resolver a superlotação da recepção presencial. O site conta com: Área de cadastro e area de login do dono; área de cadastro e de login do doguinho; agendamento; conclusao.
